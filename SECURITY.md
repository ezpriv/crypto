# Security

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on [ezpriv/crypto](https://github.com/ezpriv/crypto/security/advisories/new). Don't open a public issue.

Include the affected version, what an attacker can do, and how to reproduce it. You'll get an answer within a week. Fixes are released as a new version, and the advisory is published once users have had time to update.

What's in scope: anything where this library's format or code ([SPEC.md](SPEC.md), `src/`, `ports/`) lets someone read, forge or swap data they shouldn't. Bugs in libsodium itself go to [libsodium](https://github.com/jedisct1/libsodium/security).
